# Organizations and access

Standalone accounts are approved and managed by an administrator. Integrated
Genesys users are associated with the organization verified from their Genesys
Cloud session.

## Standalone account access

- A new standalone user submits an access request and verifies their email.
- A global administrator reviews pending requests on the Admin page.
- Administrators can approve users and assign organization access.
- Users with access to multiple organizations can select an active organization
  in the workspace header.

## Managing organizations

Global administrators can review organizations and manage local-user
assignments from the Admin page. Organization IDs are immutable, and an
organization cannot be removed while it still has users, requests, or
configuration records associated with it.

If you cannot access the workspace or an expected organization, contact your
Export Manager administrator.
