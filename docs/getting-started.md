# Getting started

Genesys Cloud Export Manager provides a workspace for reviewing configuration
and preparing exports. Sign in with the account type that was set up for you.

## Sign-in options

- Use Genesys Cloud sign-in when launching the app through a configured Genesys
  OAuth client.
- Use email sign-in if you have a standalone Export Manager account.
- Standalone accounts need administrator approval before they can access the
  workspace.

## Find your way around

- Overview summarizes the workspace and its current status.
- Resources is where configuration resources are organized.
- Export history shows recorded export activity.
- Settings contains account, connection, and organization options.
- Documentation contains these user guides.

Some parts of the workspace are still in development. See the Exports and
history guide for details about sample data and export execution.
